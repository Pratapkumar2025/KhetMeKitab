## 🌾 About

KhetMeKitab is a comprehensive educational platform designed specifically for **rural students** in India. It serves as a complete guide to **FREE** learning resources, helping students from villages and small towns access quality education without financial barriers.

**🔗 Website Link:** [https://Pratapkumar2025.github.io/KhetMeKitab/](https://Pratapkumar2025.github.io/KhetMeKitab/)

### Why KhetMeKitab?

- 🆓 **100% Free Resources** - No paid content, ever
- 🇮🇳 **Bilingual** - Hindi & English with one-click translation
- 📱 **Mobile-First** - Works perfectly on smartphones
- 🎧 **Audio/Video Focus** - Learn by listening, not just reading
- 🌐 **Offline-Friendly** - Download content for offline learning
- 📊 **Data-Efficient** - Tips to save mobile data

## ✨ Features

- **Computer Basics** - Typing, MS Office, fundamentals
- **Digital Marketing** - Google Digital Unlocked, Social Media
- **Graphic Design** - Canva, GIMP, design principles
- **Data Entry & Excel** - Formulas, pivot tables, advanced skills
- **Video Editing** - CapCut, Shotcut, effects

- Complete NCERT resources for all subjects
- Free PDF textbooks (official links)

### 🗣️ English Learning Guide
- Beginner to Intermediate learning paths
- Alphabet, pronunciation, vocabulary
- Grammar and conversation practice
- Top YouTube channels (BBC Learning English, Let's Talk)
- Free apps (Duolingo, Hello English)
- **Audio-focused content** for easy learning

### 📱 Recommended Apps & Resources
- **Essential Apps**: DIKSHA, Khan Academy, Duolingo, Hello English
- **Skill Apps**: Canva, CapCut, Microsoft Office Mobile
- **50+ YouTube Channels** - Categorized by subject and skill
- **Education News** - Latest scholarships, schemes, updates

### 🌐 Hindi Translation
- One-click language switching
- All content available in Hindi and English
- Saves language preference
- Easy for non-English speakers

## 🚀 Quick Start

### For Users (Sharing the Website)

**Simply share this link:**
```
https://Pratapkumar2025.github.io/KhetMeKitab/
```

Works on:
- ✅ Mobile phones (Android/iOS)
- ✅ Tablets
- ✅ Desktop computers
- ✅ Any modern web browser

### For Developers (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pratapkumar2025/KhetMeKitab.git
   cd KhetMeKitab
   ```

2. **Open in browser:**
   ```bash
   # Simply open index.html in any web browser
   # Or use a local server:
   python -m http.server 8000
   # Then visit: http://localhost:8000
   ```

3. **No build process needed!** Pure HTML, CSS, and JavaScript.

## 🌐 Deploying with GitHub Pages

This website is deployed using GitHub Pages. To deploy your own version:

1. **Fork this repository**
2. **Go to Settings → Pages**
3. **Select branch:** `main` or your preferred branch
4. **Select folder:** `/ (root)`
5. **Click Save**
6. Your site will be live at: `https://[your-username].github.io/KhetMeKitab/`

## 💡 How to Use (For Rural Students)

### 1️⃣ Choose Your Learning Path
- Click on **"Skill Learning Paths"** for job-oriented skills
- Click on **"NCERT Learning"** for Class 4-10 studies
- Click on **"English Guide"** to learn English

### 2️⃣ Switch Language
- Click the **"🌐 English"** button in the top-right corner
- Website switches between Hindi and English instantly

### 3️⃣ Access Free Resources
- All YouTube links open directly
- Download NCERT PDFs for free
- Install recommended apps from Play Store
- All resources are 100% free!

### 4️⃣ Learn Offline
- Download YouTube videos when you have WiFi
- Download NCERT PDFs to your phone
- Use apps' offline modes (DIKSHA, Khan Academy)
- Save data by downloading at 480p quality
