# 🚀 How to Enable GitHub Pages

Follow these simple steps to make your KhetMeKitab website live on the internet:

## Step 1: Go to Repository Settings

1. Go to your GitHub repository: `https://github.com/Pratapkumar2025/KhetMeKitab`
2. Click on **⚙️ Settings** (top menu bar)

## Step 2: Navigate to Pages

1. In the left sidebar, scroll down to find **Pages**
2. Click on **Pages**

## Step 3: Configure Source

1. Under **"Source"**, click the dropdown that says **"None"**
2. Select **`main`** branch (or whichever branch has your code)
3. Keep the folder as **`/ (root)`**
4. Click **Save**

## Step 4: Wait for Deployment

1. GitHub will start building your site (takes 1-2 minutes)
2. Refresh the page after a minute
3. You'll see a message: **"Your site is live at https://Pratapkumar2025.github.io/KhetMeKitab/"**

## Step 5: Access Your Website

Your website will be available at:
```
https://Pratapkumar2025.github.io/KhetMeKitab/
```

## 🔄 Updating the Website

Whenever you make changes:
1. Commit and push to your repository
2. GitHub Pages automatically rebuilds (takes 1-2 minutes)
3. Changes will be live!

## ✅ Verification

To verify your site is working:
1. Open the link in a browser
2. Try the Hindi/English toggle
3. Click on different sections
4. Test on mobile phone

## 🆘 Troubleshooting

**Issue: Site not loading**
- Wait 5 minutes after enabling Pages
- Clear browser cache
- Try incognito/private mode

**Issue: Changes not reflecting**
- Wait 2-3 minutes after pushing
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

**Issue: 404 Error**
- Check if the branch name is correct in Pages settings
- Ensure index.html is in the root folder
